# @zsib/board

The static decision board: **Vite 8 + React 19 + TanStack Router/Table + Apache ECharts 6**,
in-memory filtering over the lake's built JSON. No backend, no database — any static host
works, and the build output runs from a plain file server.

## Commands

Run from the repo root (Bun workspaces; this app is covered by the `apps/*` glob):

```sh
bun install                      # once, at the repo root
bun run --cwd apps/board dev     # http://localhost:5173
bun run --cwd apps/board build   # → apps/board/dist/
bun run --cwd apps/board preview # serve the built dist/
bun run --cwd apps/board typecheck
```

## Data expectations

The board fetches `./data/*.json` at runtime. That path maps to the lake output:
- **dev**: a Vite middleware in `vite.config.ts` serves `../../build/**` under `/data/**`
  (no publicDir symlink, no extra dependency).
- **build**: `vite build` copies the `build/**` JSON tree into `dist/data/` via the same
  plugin's `closeBundle` hook.

Required inputs (generated by `bun run lake` at the repo root — run it first if `build/`
is empty):

| File                       | Used by                                                       |
| -------------------------- | ------------------------------------------------------------- |
| `build/deployments.json`   | Picks, Explorer, model pages                                  |
| `build/decision.runs.json` | Picks, model pages (accuracy history, per-language stats)     |
| `build/ner.runs.json`      | model pages (merged with decision runs, tagged by track)      |
| `build/*.items/*.json`     | not rendered yet — copied/available for item-level drill-down |

The app treats the JSON as structural types (`src/types.ts`) and fails with a readable
error (root `errorComponent`) when a file is missing.

## Views

| Route                                                                                                                                          | Status                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| `/` Picks — cheapest ≥90%, fastest local on CPU, best rare-language (mean over si/is/cy from `per_language`), best open-weights, ZDR-safe only | real                                |
| `/explore` — TanStack Table with faceted filters (kind, family, provider/runner, status, ZDR) + sortable columns                               | real                                |
| `/model/$` — every deployment of one model, accuracy-over-time line (version markers), per-language heatmap, run history table                 | real                                |
| `/crossover`, `/providers`, `/planner`                                                                                                         | routed stubs (phase 5 continuation) |

Model ids contain a slash (`fastino/gliner2.5-base`), so the model page is a splat route
(`/model/$`) and `params._splat` is the model id.

## Notes

- ECharts is imported through `src/charts/echart.tsx` only (`echarts/core` + the chart
  types/components the board uses), so bundles stay tree-shaken; option builders in
  `src/charts/options.ts` are pure functions.
- Picks rank on the **decision** track only, latest `status: ok` run per deployment.
  Legacy local runs record a $0 amortised cost, so they sort as free.
- Language order/tiers mirror `catalog/languages.yaml` (duplicated in
  `src/lib/languages.ts` because the built JSON does not carry them).
- Deploy target: static host served from the site root (`base: "/"` in
  `vite.config.ts`). The router uses browser history, so configure an SPA fallback
  (e.g. GitHub Pages: copy `index.html` to `404.html`) for deep links, and change
  `base` if the site is hosted under a sub-path.
- Root wiring (`package.json` catalog, biome, CI) is owned by the repo root; no root
  changes were made for this app — the `apps/*` workspace glob already picks it up.
